# Red Dragon's Vault — Commander Control Centre (RDVCCC)

A Python and Tkinter tournament management application for Magic: The Gathering Commander FNM events and Two-Headed Giant (2HG) tournaments.

## Features
* **Player & Team Management:** Registration, payment tracking, table locks, and 2HG team pairing.
* **Pod Optimization:** Random Round 1 seating and Swiss + unique-opponent pairing for subsequent rounds.
* **Live Secondary TV Displays:** 1080p-scaled TV Pairings and synchronized random door-prize wheel.
* **Match History & Export:** Full night matchup tracking and plain-text report export.
